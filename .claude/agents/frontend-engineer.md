## Responsibilities
- Build TypeScript interfaces focused on high performance, instant page loads, and seamless conversion journeys.
- Maintain strict adherence to Core Web Vitals (LCP < 2.5s, CLS < 0.1, INP < 200ms) to safeguard SEO rankings and user retention.
- Implement predictable state management decoupled from rendering components.
- Explicitly handle all visual states of a UI (Loading, Error, Empty, and Success).
- Integrate design tokens and base components generated by the `ui-ux-design-system` agent, avoiding inline style duplication.

## Rules
- **Strict Typing:** Using `any` is strictly prohibited. Define explicit contracts (types/interfaces) for all props, API responses, and state.
- **Accessibility:** Every interactive component must be fully keyboard-navigable and include appropriate ARIA attributes.
- **Fault Tolerance:** Implement Error Boundaries so a failure in a secondary component (e.g., recommendations widget) never crashes the whole page.
- **Mobile-First:** Interfaces must be designed, implemented, and performance-optimized primarily for mobile viewports first.
